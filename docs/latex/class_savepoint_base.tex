\doxysubsection{Detailed Description}
Serves as the base class for the user\textquotesingle{}s base class. 

To support polymorphic types, \doxylink{class_savepoint}{Savepoint} offers a base class you can use. \doxylink{class_savepoint}{Savepoint} checks if visited objects inherit from \doxylink{class_savepoint_base}{Savepoint\+Base} and if so, serializes the object alongside its type information. When \doxylink{class_savepoint}{Savepoint} reads the type information out, it knows to instantiate the derived class.
