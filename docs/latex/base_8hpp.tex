Helper for concrete derived classes to implement \doxylink{class_savepoint_base}{Savepoint\+Base} methods. 

Implements Savepoint\+Derived\+Get\+String and automatically registers a factory function for the derived class. It allows a \doxylink{class_savepoint_visitor}{Savepoint\+Visitor} to to create an instance of the derived class whilst only knowing its class name.
