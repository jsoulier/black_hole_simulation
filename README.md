# Savepoint

A simple, fast, and reliable key-value database for games written in C++

### Features

- Automatic transactions
- Lazy upgrading
- UUID and spatial keys
- Inherited and nested fields
- Polymorphic types
- Arrays, vectors, sets, maps, pointers, etc

### Documentation

The source is documented with Doxygen style comments.
You can generate HTML docs with `doxygen Doxyfile`
